### Selected Work

- **[Enterprise Agentic RAG](https://github.com/Manishthakur99/enterprise-rag-gcp)** — Production-grade cyclic RAG system on GCP and LangGraph: multi-step planning, Qdrant vector retrieval, FlashRank local semantic re-ranking, and full OpenTelemetry/Logfire observability on Cloud Run.
- **[Secure-EHR Clinical Validator](https://github.com/Manishthakur99/Secure-EHR-Insight-Clinical-validator)** — Zero-trust clinical RAG and policy enforcement engine for EHR archives: BioClinical-ModernBERT embeddings in pgvector, Microsoft Presidio in-memory PHI de-identification, and NVIDIA NeMo Guardrails policy firewalls.
- **[Bramble AI App Builder](https://github.com/Manishthakur99/brambleAiAppBuilder)** ([Live](https://bramble-ai-app-builder.vercel.app)) — Full-stack generative app builder with real-time Sandpack sandbox execution: autonomous multi-file coding agent (Cline SDK), live web synthesis via webcmd, Next.js, Prisma, PostgreSQL, and Clerk billing.
- **[CodeForge](https://github.com/Manishthakur99/CodeForge)** — Full-stack LMS and automated course generation platform: React 18, Redux Toolkit, Node/Express backend, MongoDB aggregation pipelines, Razorpay payment verification, and automated YouTube Data API video enrichment.
